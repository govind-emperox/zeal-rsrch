## Initial Research-Agent Concept

The original goal was to create a research agent that can:

- Perform web search and other searches where available.
- Collate, organize, and temporarily store search results and scraped data from websites that allow it.
- Read and understand article/page contents, including nuance and core concepts.
- Produce a report in a human journalist-like style: understand, synthesize, rewrite in original words, and cite/credit sources properly.
- Delete scraped/original third-party webpage data at the end of the research process, retaining only final reports, source metadata/manifests, citations, and cleanup/audit evidence unless explicit retention is requested.

The user first considered a desktop app such as AnythingLLM or a provisioned short-lived high-end LLM host, then decided the Codex skill/app approach is likely cleaner than building a separate workaround-heavy agent stack.

## Firecrawl / Scraping Notes

The user asked how scraping would work and what Firecrawl setup would require. Working decisions:

- Firecrawl is an optional web collection tool for Codex, not necessarily a hard dependency for the first dashboard skeleton.
- The simplest route inside this Codex environment is using the installed Firecrawl plugin/skills where available.
- For local app integration, possible approaches remain:
  - Firecrawl API key through a hosted Firecrawl service.
  - Firecrawl MCP server configured for ChatGPT/Codex-style use.
  - Self-hosted Firecrawl from its open-source project, if the user wants local control.
- A separate local or LAN Docker host can be used for self-hosted support services if ports and environment variables are configured correctly.
- Scraping must respect site terms, robots.txt where applicable, paywalls, login boundaries, copyright, and rate limits.
- Release 1 should retain source metadata and final citations, not raw scraped page content, unless the user explicitly requests retention.

Suggested retained artifacts after a research task:

- Final report.
- Source manifest.
- Citation list.
- Cleanup audit.
- Optional user-uploaded files.

Suggested temporary artifacts during a task:

- Raw fetched pages.
- Parsed markdown.
- Intermediate extraction JSON.
- Search result payloads.

Suggested cleanup model:

```text
projects/<project-id>/reports/
projects/<project-id>/manifests/
projects/<project-id>/audits/
projects/<project-id>/uploads/
tmp/<task-id>/
```

Delete `tmp/<task-id>/` after successful report generation or after a failed/expired run, then write a cleanup audit.
